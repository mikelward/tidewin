# tidewin

tide on Windows: [tide for Linux](https://github.com/mikelward/tide)'s tiling
desktop and [tide for Chrome](https://github.com/mikelward/tideco)'s launcher
and dashboard, with the same keys and layouts as
[tide for macOS](https://github.com/mikelward/tidemo).

**Status: exploration.** Nothing is built yet. [SPEC.md](SPEC.md) says what
Windows allows for each of tide's features, how well and at what cost, and
compares five ways to build it (§3). [TODO.md](TODO.md) says what's next.
